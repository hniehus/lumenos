# 12. Glossary

| Term | Meaning |
|---|---|
| Boot Contract | Defined handoff agreement between bootloader and kernel |
| Bootstrap Protocol | Defined transfer from kernel bootstrap to init |
| Task / Process | Ownership and execution container |
| Thread | Schedulable execution unit |
| AddressSpace | Virtual memory context |
| VMO | Memory object used for mapping / sharing / backing memory |
| Capability | Explicit authority to use or manipulate an object |
| Channel / Endpoint | IPC primitive |
| DeviceHandle | Controlled representation of device-facing access |
| Fastpath | The most latency-sensitive core execution path, especially trap/syscall/switch/IPC |
| Minimal Boot Path | Smallest end-to-end path from bootloader to init that proves architectural viability |
